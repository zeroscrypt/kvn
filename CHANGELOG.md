# Changelog

Формат по мотивам [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [0.1.0] — 2026-10-16

Первая версия: десктопный клиент под macOS (первичная проверка), Linux и
Windows собираются из того же кода (не проверены — так и помечены).

### Добавлено

- **Ядро (`kvn-core`)**: типизированная модель профиля; парсеры share-ссылок
  VLESS / VMess / Trojan / Shadowsocks (включая подписочные payload-ы,
  base64 и plain), с явными ошибками вместо молчаливых потерь; генератор
  полного клиентского конфига Xray (SOCKS+HTTP inbound, REALITY/TLS,
  TCP/WS/gRPC/HTTPUpgrade/XHTTP, fragment anti-DPI, маршрутизация bypass);
  чистая машина состояний соединения с ограниченными авто-реконнектами;
  `Secret`-обёртка и редакция ссылок для логов.
- **Движок (`kvn-engine`)**: управление процессом Xray (spawn/stop/SIGTERM
  с grace, отдельная сессия), валидация конфига самим движком
  (`xray run -test`), проверка готовности «реальным трафиком» через
  SOCKS5, статистика через `xray api statsquery`, установка официального
  релиза с проверкой SHA-256 (digest-ы вшиты), защита от zip-slip.
- **Приложение (`apps/desktop`)**: терминальный UI (vanilla TS + Vite):
  список профилей, статус с латентностью/аптаймом/скоростью и объёмом
  трафика, журнал событий (в UI и дублируется в `logs/kvn.log`), командная
  палитра (⌘K), импорт ссылок/файла/подписок, настройки, тестовый режим без
  реального VPN, самодиагностика UI (загрузка и JS-ошибки пишутся в журнал),
  диагностический экспорт (без секретов), системный прокси на macOS и
  best-effort в GNOME, автоскачивание движка из UI.
- **Движок в комплекте (ADR 0005)**: релизные сборки несут закреплённый
  Xray-core как sidecar; единый манифест пина `core/xray.json` (релиз,
  архивы, SHA-256, target-триплеты) встраивается в бинарь на этапе
  компиляции; в настройках виден источник движка и доступна
  информационная проверка обновлений — новое ядро приезжает с новой
  версией KVN, пин обновляет проверяемый PR воркфлоу `core-update.yml`.
- **Меню-бар (трей)**: значок-щит (native template-иконка, следует
  светлой/тёмной теме), меню: статус, подключение/отключение, открытие
  окна, настройки, выход; закрытие окна скрывает приложение в трей —
  туннель продолжает работать; выход (в т.ч. Cmd+Q) выполняет
  graceful-остановку движка.
- **Локализация и типографика**: переключение RU/EN по всему интерфейсу
  (по умолчанию русский, выбор сохраняется и применяется мгновенно);
  окно настроек переработано (прокрутка, залипающие кнопки действий);
  шрифт Geist Mono (OFL-1.1) — в комплекте.
- **Релиз-инженерия**: CI на macOS/Linux/Windows (юнит- и живые
  интеграционные тесты, `fmt`, `clippy -D warnings`, `cargo-deny`,
  conventional-commit + DCO), release-please для версий, тег → сборка →
  provenance-аттестации + `SHA256SUMS` в черновик релиза (публикация без
  пересборки); CodeQL, OpenSSF Scorecard, Dependabot; все actions
  пришпилены к commit-SHA.
- **Документация**: `docs/RESEARCH.md`, `docs/COMPATIBILITY.md`,
  `docs/ARCHITECTURE.md`, `docs/SECURITY.md`, `docs/BENCHMARKS.md`,
  `docs/PLATFORM_SUPPORT.md`, ADR 0001–0005, `CONTRIBUTING.md`,
  `SECURITY.md`, `CODE_OF_CONDUCT.md`.
- **Тесты**: 62 юнит-теста ядра, 16 юнит- и 4 интеграционных теста движка
  (реальные Xray-процессы, живой трафик через VLESS TCP/WS/XHTTP+REALITY),
  17 тестов приложения — всего 99.

### Известные ограничения

- Транспорты KCP/QUIC распознаются при импорте, но не собираются в конфиг
  (явная ошибка при подключении).
- Системный прокси: Windows — не реализовано; Linux — только GNOME.
- TUN-режим — не реализован (см. ADR 0004).
- Linux/Windows-сборки не проверены на живых системах (см.
  `docs/PLATFORM_SUPPORT.md`).
- macOS-релизы не подписаны (нет Apple Developer account): скачивайте
  только из GitHub Releases и сверяйте `SHA256SUMS`/provenance-аттестацию.
