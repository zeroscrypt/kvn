# Совместимость: протоколы, транспорты, ссылки

Матрица отражает **фактическое** поведение кода: что распознаётся при
импорте и что реально собирается в клиентский конфиг Xray. Всё, что не
собирается, отклоняется явной ошибкой — молчаливых потерь параметров нет.

## Протоколы

| Протокол | Импорт | Подключение | Примечания |
|---|---|---|---|
| VLESS | ✅ | ✅ | UUID (dashed/compact; кастомные id < 30 байт), `flow=xtls-rprx-vision`, `encryption=none`/`mlkem768x25519plus*` |
| VMess | ✅ | ✅ | `v` 1/2, `aid`, шифры: auto/none/zero/aes-128-gcm/chacha20-poly1305 и др. (полный список — в `uri/vmess.rs`); legacy base64-конфиг (v2rayN JSON) поддержан |
| Trojan | ✅ | ✅ | `password` (percent-encoded), `flow` (xtls-rprx-vision) |
| Shadowsocks | ✅ | ✅ | SIP002 (percent-encoded и полностью base64) + SS-2022; методы: aes-*-gcm, chacha20-ietf-poly1305, xchacha20-ietf-poly1305, none, `2022-blake3-*` |

## Транспорты (для VLESS/VMess/Trojan)

| `type=` | Импорт | Подключение | Параметры |
|---|---|---|---|
| `tcp` (или пусто) | ✅ | ✅ | `headerType=none/http`; `path`, `host` (HTTP header-маскировка) |
| `ws` | ✅ | ✅ | `path`, `host` |
| `grpc` | ✅ | ✅ | `serviceName` (фолбэк — `path`), `mode` (gun/multi), `authority` |
| `xhttp` / `splithttp` | ✅ | ✅ | `path`, `host`, `mode`, `x_padding_bytes`, вложенный `extra` (JSON) |
| `httpupgrade` | ✅ | ✅ | `path`, `host` |
| `kcp` | ✅ (парсится) | ❌ явная ошибка | распознаём, но конфиг не собираем — в UI предупреждение |
| `quic` | ✅ (парсится) | ❌ явная ошибка | то же |
| любой другой | ❌ ошибка импорта | — | `unsupported transport` |

## Security (для VLESS/VMess/Trojan)

| `security=` | Импорт | Подключение | Параметры |
|---|---|---|---|
| `none` (или пусто) | ✅ | ✅ | — |
| `tls` | ✅ | ✅ | `sni` (алиас — `peer`), `alpn` (список через запятую), `fp` (uTLS, проверяется по списку), `insecure`/`allowInsecure` → **предупреждение в UI** |
| `reality` | ✅ | ✅ | `pbk` (обязателен), `sni` (обязателен), `sid`, `spx`, `fp`, `pcs` |
| любой другой | ❌ ошибка импорта | — | `unsupported security` |

## XHTTP `extra`

3x-ui кладёт расширенные настройки XHTTP в query-параметр `extra` как
JSON-строку. KVN:

- сохраняет blob **дословно** в профиле (и в `state.json`);
- при сборке конфига пропускает только известные ключи
  `splithttp`-схемы Xray-core; неизвестные ключи **не выкидываются молча**,
  а перечисляются в `notes`, которые видны в журнале событий.

Также поддержан «плоский» `x_padding_bytes` (эмитится 3x-ui в некоторых
версиях) — конвертируется в ключ `xPaddingBytes` внутри `extra`.

## Ссылки и подписки

| Формат | Поддержка |
|---|---|
| Список ссылок, по одной в строке | ✅ |
| Одна ссылка | ✅ |
| Base64 (с переносами) поверх списка — формат подписок 3x-ui/v2rayN | ✅ |
| `sub://`/`subscription://`-разворачивание | ❌ (импортируйте тело подписки) |
| URL подписки | ✅ отдельной сущностью «подписка» (кнопка/модалка Subscriptions), скачивание через `http(s)`, с UA `kvn/…` |

## 3x-ui: что именно проверено по исходникам

Формат share-ссылок сверен с `internal/sub/service.go` (ветка 3.x):
порядок параметров, `x_padding_bytes`, `extra`, кодирование remark и
percent-encoding значений. Панель 3x-ui по сети **не опрашивается**:
KVN не умеет и не хочет знать логин/пароль администратора панели — только
ссылки и подписки, которые вы сами скопировали.

## Известные ограничения совместимости

- KCP/QUIC: не собираются (см. таблицы выше).
- `flows` кроме `xtls-rprx-vision`/`-udp443` отклоняются при импорте.
- Shadowsocks-плагины (`plugin=…`) отклоняются явной ошибкой — Xray их не
  поддерживает; в SS-2022 пароль с `:` должен быть percent-encoded (как и
  в ссылках панели).
- Fragment (anti-DPI) применяется как локальный TLS-fragment; имеет смысл
  на VLESS/TLS-профилях, настраивается в Settings, по умолчанию выключен.
