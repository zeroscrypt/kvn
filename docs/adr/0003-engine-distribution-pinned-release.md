# ADR 0003. Распространение движка: скачивание официального релиза с проверкой SHA-256

Статус: принято (2026-10). Частично заменено
[ADR 0005](0005-bundled-engine-sidecar.md): релизные сборки поставляют движок
в комплекте (sidecar), а встроенная установка осталась путём
обновления/восстановления. Пиннинг релиза и проверка SHA-256 — в силе.

## Контекст

Приложению нужен бинарник Xray-core. Варианты:

1. Складывать движок внутрь репозитория/сборки;
2. Скачивать релиз официального GitHub-проекта во время работы;
3. Требовать от пользователя самостоятельно установить Xray.

## Решение

Комбинируем 2 и 3:

- **В приложении есть кнопка «Установить движок»**: скачивается архив из
  официального релиза `XTLS/Xray-core` (зафиксированная версия
  `XRAY_RELEASE`, сейчас `v26.3.27` для всех платформ), **SHA-256 архива
  вшит в исходный код** (`crates/kvn-engine/src/install.rs`). Даже подмена
  релиза на GitHub или MITM не пройдёт проверку.
- Из архива извлекается **только бинарник `xray`** (защита от zip-slip:
  имена с `..`/абсолютные пути отклоняются), записывается атомарно, на
  unix выставляется executable-бит.
- Установленный бинарник обязан пройти `xray version` — иначе он не
  считается движком.
- Пользователь может **указать свой бинарник** (Settings → Engine path):
  он тоже проходит пробу `xray version`, но работает «как есть» — за его
  происхождение отвечает пользователь.
- Порядок поиска: пользовательский путь → установка KVN → `xray` в `PATH`.

## Последствия

+ Репозиторий остаётся маленьким, лицензия Xray не смешивается с нашей.
+ Пользователь без интернета или с собственным Xray-ом полностью себя
  обслуживает (путь в настройках).
− Нужен первый сетевой запрос за движком (только по явному действию, не
  автоматически).
− При обновлении версии движка нужно пере-пинить пять digest-ов (скрипт
  `scripts/fetch-xray.sh` помогает подготовить значения для всех платформ).

## Альтернативы и почему нет

- **Вендорить бинарники в репозиторий** — раздувает репозиторий, устаревает,
  и обновления движка становятся релизами приложения.
- **Скачивать без проверки digest** — цепочка поставки не защищена.
- **Только «сделай сам»** — противоречит цели «работает из коробки».
